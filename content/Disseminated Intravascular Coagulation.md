Secondary to a primary condition

Excessive clotting → ischemia
Excessive clotting → use up all clotting factors → bleed

Rapid clot lysis → ↑[[Fibrin Degradation Products]] → bleed

Signs and symptoms:
- [[Fibrinogen]] < 200 mg/dL
- ↑[[Prothrombin Time|PT]] ↑[[Activated Partial Thromboplastin Time|aPTT]]
- ↑[[Fibrin Degradation Products|FDPs]]
- [[D-Dimer]] > 500 ng/mL
- [[Platelet]] < 100,000

Treatment:
- Treat underlying cause
- [[heparin]]
- Once [[Prothrombin Time|PT]] and [[Activated Partial Thromboplastin Time|aPTT]] are normal for heparin, start [[Fresh Frozen Plasma]] and [[Cryoprecipitate]]
- [[Platelet]]  transfusion if < 20,000
